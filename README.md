# Forja

Web-app de entrenamiento: elige equipo y músculos, sigue cada ejercicio con fotos animadas y vídeo, registra tus series con temporizador de descanso, sigue programas y consulta tus estadísticas.

Ábrela en Safari en el iPhone y pulsa **Compartir → Añadir a pantalla de inicio**. Funciona sin conexión y tus datos se guardan solo en tu dispositivo.

Fotos de ejercicios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (dominio público).
